# Dataset

Download `fake_job_postings.csv` from Kaggle:

https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction

Place the file in this `data/` folder, then use the sidebar in the app to upload and train.

Expected columns: `title`, `company_profile`, `description`, `requirements`, `benefits`, `fraudulent`
